# LOKANDA

## Open in IntelliJ IDEA
1. Extract this archive.
2. In IntelliJ IDEA, choose **File > Open** and select this folder's `pom.xml`.
3. Choose **Open as Project** and allow Maven to reload dependencies.
4. Set **Project SDK** and **Maven Runner JRE** to JDK 25.
5. Run `com.lokanda.hotel.console.ConsoleMain` for the console interface.

The project uses Java 25 and Maven. The `target` folder is intentionally excluded; Maven recreates it during compilation.
